## 🚀 API Интеграция

### REST API Клиент (api.js)

```javascript
// Аутентификация
api.login(email, password)
api.logout()
api.register(userData)
api.refreshAccessToken()

// Профиль
api.getProfile()
api.updateProfile(userData)

// Контент

api.getTags(params)
api.getBanners(params)

// Формы

api.markMessageRead(messageId)
api.replyMessage(messageId, reply)
```

## 🚀 Начало работы

### 1. Сбор статических файлов
```bash
python manage.py collectstatic --noinput
```

### 2. Запуск сервера
```bash
python manage.py runserver
```

### 3. Доступ к приложению
```
http://localhost:8000/
```

### 4. Переключение языков
```
http://localhost:8000/kg/  (Кыргызский)
http://localhost:8000/ru/  (Русский)
http://localhost:8000/ar/  (Арабский)
```
